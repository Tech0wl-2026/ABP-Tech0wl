# Daily Scrum — TechOwl

Esta pasta reúne os registros das reuniões diárias da equipe da ABP.

## Como fazemos as dailys

As reuniões duram até **15 minutos**. Cada integrante conta brevemente no que está trabalhando naquele dia, e o responsável pelo registro anota uma frase por pessoa.

Cada arquivo contém apenas **a data, os integrantes e suas atividades do dia**.

## Como registrar

1. Copiar [TEMPLATE.md](TEMPLATE.md) e preencher a data e as atividades relatadas.
2. Salvar um arquivo por dia de reunião, com o nome `AAAA-MM-DD.md`.
3. Adicionar o link do novo registro à lista abaixo.

Adicionar novos registros nos dias em que houver Daily Scrum. Se faltar o relato de alguém, deixar a atividade em branco ou escrever “A informar”.
