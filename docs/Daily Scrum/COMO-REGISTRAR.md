# Como registrar a Daily Scrum

As dailys duram até 15 minutos. Cada integrante conta brevemente no que está trabalhando naquele dia; o registro traz uma frase por pessoa, sem campo de ânimo.

1. Copiar [TEMPLATE.md](TEMPLATE.md).
2. Preencher a data, os integrantes e as atividades relatadas.
3. Salvar como `AAAA-MM-DD.md`, com um arquivo por dia de reunião.
4. Adicionar o link no [README](README.md).

Criar registros nos dias em que houver Daily Scrum. Quando faltar um relato, deixar a atividade em branco ou escrever “A informar”.
