## Conferência visual

Antes de considerar uma tela pronta, comparar o conteúdo, a hierarquia, as fontes, os espaçamentos, as imagens, os recortes e os estados interativos. Conferir também navegação por teclado, foco visível, legibilidade e ausência de rolagem horizontal.

Os screenshots do protótipo servem para comparação, não como imagem única da página implementada. Links temporários de assets não devem permanecer no código do site.
