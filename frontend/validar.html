Validação Pública de Certificado

Consulte a autenticidade e os dados oficiais de um certificado emitido pelo portal Aprendizagem Ágil.

Como validar:

1. Escaneie o QR Code presente no corpo do certificado em PDF para abrir esta página com o código preenchido automaticamente; ou

2. Cole o código de registro (hash) impresso abaixo do QR Code no campo abaixo e clique em Verificar.

Por segurança e conformidade com a LGPD, apenas os dados públicos necessários para comprovação de autenticidade são exibidos.
