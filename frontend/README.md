# Frontend

Páginas públicas do Aprendizagem Ágil, em HTML, CSS e JavaScript, com versões para computador e celular.

| Arquivo ou pasta | Conteúdo |
|---|---|
| [index.html](index.html) | Home, apresentação, benefícios e docentes. |
| [curso.html](curso.html) | Apresentação dos módulos, depoimentos ilustrativos e informações do certificado. |
| [sobre.html](sobre.html) | Apresentação do projeto e da equipe Tech0wl. |
| [css/style.css](css/style.css) | Fontes, cores, componentes e estilos responsivos. |
| [js/app.js](js/app.js) | Foco nas seções acessadas pelas âncoras da página. |
| [assets/figma](assets/figma) | Ilustração original e recursos locais de apoio ao layout. |
| [assets/fonts](assets/fonts) | Fontes e licenças de uso. |
| [assets/questoes](assets/questoes) | Imagens da amostra inicial de questões. |
| [Dockerfile](Dockerfile) | Imagem do frontend. |
| [nginx.conf](nginx.conf) | Servidor das páginas e encaminhamento de `/api/`. |
